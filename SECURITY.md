# Política de segurança

O foco da manutenção é a versão atual da branch `main`. Não há compromisso de correções retroativas para tags antigas.

## Como reportar

Informe vulnerabilidades de forma privada pela opção **Report a vulnerability** na [aba Security](https://github.com/Joaovictoreth1/Coworking-/security), se disponível. Se o formulário não estiver habilitado, procure um canal privado de contato no [perfil do mantenedor](https://github.com/Joaovictoreth1). Não publique o relatório em uma issue ou em um pull request.

Inclua a versão ou commit afetado, o componente, o impacto observado e evidências suficientes para análise. Remova tokens, senhas e dados pessoais. Use apenas ambientes e dados para os quais você tem autorização.

Combine a divulgação pública com o mantenedor para dar tempo de avaliar o impacto e preparar uma correção. Não há prazo de resposta garantido.
