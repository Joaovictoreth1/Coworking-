# Roadmap técnico

Este documento registra propostas, não datas de entrega. Para o estado atual, veja o [README](README.md) e o [changelog](CHANGELOG.md).

| Prioridade | Proposta | Critério de conclusão |
| --- | --- | --- |
| P1 | Documentar a API em OpenAPI | Cobrir autenticação, catálogo, reservas e erros de validação, com exemplos testados. |
| P1 | Automatizar a jornada de reserva no navegador | Verificar login, consulta de disponibilidade, criação e cancelamento com dados isolados na CI. |
| P2 | Avaliar a consolidação de `bookings` e `reservations` | Mapear consumidores e diferenças de contrato; registrar a decisão e uma estratégia de compatibilidade. |

Sugestões são bem-vindas pelas [issues](https://github.com/Joaovictoreth1/Coworking-/issues/new/choose). Descreva o problema antes de propor uma solução.
